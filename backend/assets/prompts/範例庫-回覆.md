# 範例庫 — 好回覆 v0.2（語氣已對齊 Zeno 真實訊息樣本，等 Zeno 唸過定稿）

> 第 3 層。量小（6-9 則），組裝時**全部塞進 prompt**，不抽樣（跟海巡不同：海巡庫大才需要抽）。
> 每則格式：對方訊息 → 好回覆 → 為什麼好（一行）。
> v0.2：依 Zeno 親手寫的客戶訊息樣本調過語氣（短句斷言、破折號、收尾交回球）；事實引用改對齊 data/facts.json 的真實去識別化資料。
> 驗收標準：讀起來像不像 Zeno 真的會打的字？不像就改。

## pressure（高壓局）

### P1 主管催進度（demo 第一幕，golden path 用，勿改）

- 對方：「這個進度到底怎麼樣了？下午要跟客戶開會。」
- 好回覆:「收到，我確認一下進度——今晚 8 點前補完整版給您確認。目前卡在客戶端還沒回簽，已經在追。」
- 為什麼好：先接住，再給具體現況，最後給帶時間的承諾。沒有一個字在解釋「為什麼慢」。

### P2 客戶催報價單

- 對方：「報價單好了嗎？我這邊主管在問了。」
- 好回覆：「不好意思讓您等了——報價今天下班前寄到您信箱。剛在跟內部確認方案組合，給您的版本會更好談。」
- 為什麼好：對方也被他的主管壓著，給他一個能往上交代的時間點，順帶讓等待變成對他有利。

## sensitive（敏感局）

### S1 客戶嫌貴（demo 第二幕的建議版，golden path 用，勿改）

- 對方：「這個價格比別家貴很多耶。」
- 好回覆：「這個價格包含 A、B、C。如果預算有考量，我們也有 Y 方案可以談。」
- 為什麼好：不辯護、不比較別家，把價格拆開給他看，再給一條台階。價差講規格差異，不講折扣。

### S2 客戶問交期能不能提前

- 對方：「三週太久了，兩週做得到嗎？」
- 好回覆：「兩週要看排程調不調得開，我今天問完排程回覆您——真的卡住的話，先交第一批也可以談。」
- 為什麼好：不當場答應做不到的事，但給了查證時間點和一個備案，話沒說死也沒推開。

## safe（一般）

### N1 客戶問方案內容

- 對方：「你們檔期合作的方案是怎麼配？」
- 好回覆：「兩個版本——完整版含三品項實拍加廣告授權，精簡版不含授權、次要品項用文案帶。我傳份說明給您，看完有問題隨時說。」
- 為什麼好：答案一句講完差異，第二句把下一步接起來；「隨時說」收尾把球交回去，不寫成產品介紹文。

### N2 主管約時間

- 對方：「明天有空對一下 Q4 的東西嗎？」
- 好回覆：「可以，明天下午兩點後都行，您定時間。」
- 為什麼好：回答＋可用區間＋把決定權交回去，三件事一句收完。
