# examples/ — PDF 知識庫範例檔（fixture）

配合 Brian 後端改吃 PDF 的架構，這批是 ingestion 測試用的範例 PDF。

**全部是虛構示範資料**：483 位使用者、9.6 顆星、效率提升 70%、媒體報導、獎項——人物與數字均為合成，每份 PDF 頁尾都有聲明。

## 使用規則

- 用途：測 PDF 解析、切塊、來源標註 pipeline。
- **不要餵進評審會問到的正式知識庫**——[README-知識庫.md](../README-知識庫.md) 的 dogfooding 規則是「只放可查證的事實、不放自我評價」，這批 fixture 全是反例，混進去會打破誠實底線。
- 產生腳本：`/tmp/gen_example_pdfs.py`（一次性，未入 repo；要重產跟 Claude 說一聲即可）。
